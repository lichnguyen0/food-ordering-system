# Kế hoạch tích hợp OpenStreetMaps cho hệ thống Food Ordering

## Tổng quan

Tích hợp OpenStreetMaps (OSM) + Leaflet.js để tính toán khoảng cách thực tế cho 3 chức năng chính:

1. **Trang Home**: Định vị người dùng, hiển thị nhà hàng gần nhất
2. **Trang chi tiết nhà hàng**: Tính khoảng cách thực tế đến người dùng
3. **Trang checkout**: Tính phí giao hàng dựa trên khoảng cách thực tế

---

## Kiến trúc hệ thống

```
┌─────────────────────────────────────────────────────────────────┐
│                         Frontend (Browser)                       │

│  DistanceService     → Tính khoảng cách (Haversine)             │

│  Restaurant entity   → Lưu lat/long                               │
│  OrderController     → Truyền dữ liệu khoảng cách               │

```

```javascript
// Thêm vào file hiện có
let map;
let shipperMarker;

function initShipperMap(lat, lng) {
    map = L.map('shipper-map').setView([lat, lng], 15);
    L.tileLayer('https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png').addTo(map);
    shipperMarker = L.marker([lat, lng]).addTo(map);
}

// Cập nhật vị trí khi shipper di chuyển
function updateShipperLocation(order) {
    if (shipperMarker) {
        shipperMarker.setLatLng([order.deliveryLat, order.deliveryLng]);
    }
}
```

## API Rate Limiting Considerations

| API | Free Tier | Recommended for Production |
|-----|-----------|---------------------------|
| Nominatim | 1 req/sec | Mapbox Geocoding ($0.75/1000 req) |
| OSRM | 1 req/sec | Google Distance Matrix ($5/1000 req) |

**Kế hoạch mạnh dự phòng:**
1. Cache kết quả geocoding trong DB
2. Sử dụng Redis để cache trong 24h
3. Fallback to hardcoded values nếu API lỗi
