# Plan: Thêm phân trang cho trang Danh sách nhà hàng (Admin)

## Mục tiêu
Thêm phân trang cho trang `/admin/restaurants` (Danh sách nhà hàng) với **10 mục/trang**, sử dụng **Spring Data Pageable** — chuẩn JPA + Thymeleaf. Các lớp CSS phân trang đã có sẵn trong `admin-style.css` (dòng 907–950).

---

## Các bước thực hiện

### 1. Cập nhật Controller — `AdminRestaurantController.java`
- Thay `restaurantRepository.findAll()` bằng `restaurantRepository.findAll(Pageable.of(page, size))`
- Thêm 2 tham số: `@RequestParam(defaultValue = "0") int page` và `@RequestParam(defaultValue = "10") int size`
- Thêm các thuộc tính vào Model: `totalPages`, `currentPage`, `pageSize`, `totalElements`
- Giữ nguyên toàn bộ các endpoint khác

### 2. Cập nhật Template — `restaurant-list.html`
- Thêm tiêu đề trang tiếng Việt: `Danh sách nhà hàng`
- Thêm footer phân trang (HTML chỉ) sau bảng nhà hàng, sử dụng **các lớp CSS hiện có** trong `admin-style.css`:
  - `.card-footer-pagination` (wrapper chính)
  - `.pagination-info` (hiển thị "Showing 1 to 10 of 25 entries")
  - `.pagination-btns` (wrapper nút)
  - `.page-btn`, `.page-btn.active`
  - `.page-btn-prev`, `.page-btn-next`
- `page-link` thực hiện phân trang bằng `?page=...` URL param

### 3. Không cần sửa CSS
Các lớp phân trang đã được định nghĩa đầy đủ trong `admin-style.css`. Không viết CSS/JS mới.

### 4. Test
- Xác minh phân trang hoạt động đúng, các nút Next/Prev và số trang hoạt động, URL giữ đúng page param.
